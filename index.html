Integrating Brain-based Knowledge with external Knowledge

Using a (hypothetical) Semantic Brain-Computer Interface


Opportunities using current BCI technology

BCIs can encode and decode sensory information


  • RQ1: “How can human senses and actuators be semantically modeled?”

    e.g. Robotic Teleoperation

  • RQ2: “How can link semantics aid humans in navigating data graphs using BCIs?”

    e.g. Web or Knowledge Graph navigation

Opportunities using future BCI technology

BCIs cannot extract or inject knowledge


  • RQ3: “How can biological semantic memory be mapped to and from symbolic knowledge?”

    Memories are stored differently across people

  • RQ4: “How can biological reasoning be mapped to and from symbolic and subsymbolic reasoning?”

    Languages to exchange reasoning and contexts

  • RQ5: “How can we model ownership and access control for biological memories?”

    Are current authorization mechanisms sufficient?
